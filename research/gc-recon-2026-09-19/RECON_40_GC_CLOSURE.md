TASK-378 (2026-09-20, тик 19:08 +08). Статус: **CLOSURE-THEOREM** — закрытие
в силе при подтверждении легом s7200 (см. фальсификационную оговорку §6).
Прецедент: RECON-17/20 STEAL («доказанное закрытие вердикт-доком с потолком <10%»).

## 1. Лейн

GC-лейн — последний открытый лейн свежих профилей после RECON-38 (закрытие
ранка сцены: broadphase/fluid/movement/volatile — все разложены, ни одного
гомогенного под-лейна ≥5%). Две поверхности:

- **STW-паузы** (G1 Evacuation + Remark/Cleanup) — внутри тикового wall-clock.
- **Параллельный GC-CPU** (refinement + concurrent-циклы) — конкуренция за 4 ядра
  с 4 тик-воркерами.

База s7198 (банк v3, ванильный G1, Xmx10G): 246 событий / 19.5188s total
(6.5% 300s-окна), avg 79.34ms, max 178.7ms; young-срез: 163 эвакуации ≈ 19.0s,
avg 117ms, медиана 126ms. GC-VM CPU: 37% сэмплов (126k, s7198).

## 2. Эмпирика v1 (s7199, run 35503592912, gc_tune=1)

Флаги: MaxGCPauseMillis=40 + IHOP=35 + G1HeapRegionSize=8m + AlwaysPreTouch.
Результат: TPS 1.5 @ 6450600 → normalized −2.9% / absolute −6.2% (двойной бар
fail); young 621 (база 163), total_pause 44.4s = 2.3× базы, avg 71.4ms (лучше),
max 153.6ms (лучше), Full=0.

Руут-кауз по живому gc.log: pause-target=40 сжал eden до 11..23 регионов × 8M
(90..184M) → эвакуации каждые ~70мс. Линейная модель по двум легам
`T = n·F + C/tp`: **F ≈ 60ms фиксированной стоимости на эвакуацию**
(roots/remset/queue processing — НЕ масштабируется молодым), copy-throughput
≈ 4.35GB/s. База: 163×60 ≈ 9.8s fixed + ~9.2s copy. Молодую растянуть нельзя:
eden базы 301 регион уже у капа G1MaxNewSizePercent 60% × heap max 10G.

## 3. Потолочная теорема (ось 2, absolute median5)

Бар оси 2: +10% TPS = +0.16 абсолютных (1.60 → ≥1.76). Полное устранение STW
даёт максимум `19.5188s / 300s = +6.5%` TPS **даже при конверсии 1:1** —
уже ниже бара. Эмпирическая конверсия строго sub-1:1: v1 добавил +24.9s STW и
потерял только 3% normalized → |конверсия| ≈ 0.1..0.4:1 (median5 pause-толерантен:
пауза бьёт один тик 5s-окна, медиана по окнам устойчива). Реальный потолок
STW-компоненты: ≤ +2.5%.

Параллельная компонента: обнуление GC-CPU (37% сэмплов) освобождает ≤ 37%/4
ядер ≈ +9.25% core-времени ВЕРХНИЙ БОНД, но (а) тик-воркеры не 100% core-starved
(park 12.8% wall-сэмполов), (б) та же v1-эмпирика связывает конверсию far-below
linear. Совместно: **ни одна комбинация GC-флагов не достигает +10% ни по одной
оси** → лейн математически не проходит двойной бар.

## 5. Следствия

GC-лейн закрывается с потолком <10% (RECON-17/20 прецедент). Свежие профили
после RECON-38 + RECON-40 не содержат ни одного неразложенного лейна ≥5%:
**1.5-1.6 TPS @ 150k = семантический минимум ванильного тика** на этой сцене и
классе железа (банк v3 = ×2.0-2.7 от базы 0.6-0.8). Рост ≥10% только сменой
класса (сцена / parity-профиль / железо) — решение владельца.

## 6. Фальсификационная оговорка

Закрытие аннулируется, если s7200 (или любой GC-конфиг-лег) пройдёт двойной бар
(обе оси ≥+10%) → тогда min-of-2 подтверждающий лег + banking v4 = v3 + gc_tune.
Иначе закрытие финально по абсорбу s7200 (ABSORB_S7200.md) в тике 19:4x.
