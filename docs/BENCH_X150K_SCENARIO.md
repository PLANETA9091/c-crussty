## 2. Сцена X150K (главное изменение)

**ЮНИТ x150000 — УТОЧНЕНО ВЛАДЕЛЬЦЕМ (S7-128, live)**: «x150000 — это к
скорости выполнения какой-то функции из боттлнеков, которые топ-1, например
по использованию». НЕ количество сущностей (гипотеза DRAFT v1 refuted), а
**планка ускорения СКОРОСТИ ВЫПОЛНЕНИЯ топ-1 функции-бутылочного горлышка**.
Операционализация (вердикт агента, делегирован владельцем: «вердикт уже
твой»): функция на кэш-гард-пути должна исчезнуть из профиля — self-time
доля → ниже видимости профайлера (~0.1% класса), т.е. «бутылочное горлышко
больше не нагружает тик»; эквивалентный механизм = устранение избыточной
работы (memoization/guard/dirty-флаг), где амортизированная стоимость на
результат падает на порядки. Выбор топ-1 функции и порядок атаки — автономия
агента. Сцена нагрузки остаётся: ВСЕ форс-чанки + ВСЁ ЖИВОЕ (спавн/деспавн
как с игроками) — «всё работает так же как в ваниле».
