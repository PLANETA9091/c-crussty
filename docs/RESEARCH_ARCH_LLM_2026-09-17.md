## C. Красная команда (q3) — вердикты по кандидатам следующего раунда

1. **ENT-BP wiring — NO-GO СОЛО.** Честный потолок: replaceable core 2.27% absolute → реалистично 1.5–1.8% MSPT (predicate retention ~1.3% сохраняется по G1 + JNI-цена) **< гейта ≥3%**. → Ядро `entity_mirror.rs` остаётся инфраструктурой (готово, 72/72 тестов); production-клейм припаркован. Возможная future-банда: ENT-BP + PUSH-MEMO (0.99%) + ENT-DATA (0.79%) — теоретический потолок ~4%, реалистично sub-3 — вторичный приоритет.
2. **PALETTE zero-copy lens — NO-GO.** Per-get JNI-вход (десятки нс) на 10k+ вызовов/тик съедает весь выигрыш от 3.7% leaf; чистый эффект ~0%. Рычаг возможен ТОЛЬКО как батч-линза (оптовые выгрузки секций), а профиль показывает per-get паттерн → лейн закрыт в этой постановке.
3. **BOAT whole-body hot-patch — GO, ПОБЕДИТЕЛЬ.** AbstractBoat.tick = 9.66% presence, крупнейший одиночный драйвер bucket'а entities. Потолок q3: 4.5–6.2% MSPT > гейта. Прецеденты есть (TASK-148 PerlinNoise native: −12.3% wall bit-exact; SingleUserAreaMap.update whole-body: 5075→3320B).
4. **RANDOM-TICK BATCH-RNG — GO (резерв).** Кластер 4.5%; механизм: один JNI-вызов на чанк-тик заполняет буфер случайных чисел бит-точным LCG (Java Random = 48-bit LCG, воспроизводится в Rust 1:1) — SIMD-параллельность потока не нужна, нужна амортизация JNI-входа. Прогноз q3: 3.2%.
5. **GC allocation-shape — УСЛОВНЫЙ GO.** 2.8–4.7%, но нижняя граница sub-gate; требует allocation-профиля (метрика F2) перед пререгистрацией.

## D. ПРЕДРЕГИСТРАЦИЯ ПОБЕДИТЕЛЯ: BOAT (task162, S7-93)

- **Мишень:** `AbstractBoat.tick` (net.minecraft.world.entity.vehicle) — 9.66% presence в run#10; механизм — whole-body hot-patch тела метода (прецедент area_map) ИЛИ native-core с подготовленным списком AABB (гибрид, решение после анатомии).
- **ШАГ 0 (килл-критерий ДО реализации):** exact-frame анатомия AbstractBoat.tick из raw collapsed run#10: self-time + доля SIMD-able callees против доли upcalls в мир (getBlock/collision — JNI-upcalls дороги). Если заменяемая база < 4% MSPT → рычаг ЧЕСТНО ОПРОВЕРГНУТ до единой строки продакшн-кода, следующий кандидат = BATCH-RNG (C/4).
- **Гейт (PRIMARY):** ≥3% MSPT на CI A/B (world-bench-3, min-of-2 dispatch, env CRUSSTY_NATIVE_BOAT).
- **Parity-протокол:** bit-exact позиция/скорость/флаги лодки на фиксированном сиде: 20,000 тиков по сценариям (вода/лава/лёд/сухопутье/падение/пассажир); расхождение любого поля = FAIL. Клиентский lerp — сетевой слой, не тик-логика: сервер authoritative, предсказание клиента не затрагивается (смягчение риска q3).
- **Поверхность:** пассажиры/сущности-взаимодействия — делегация вверх через синтезированный bridge (НЕ руками Java); финальная поверхность фиксируется после ШАГА 0.
- **Лестница:** (0) анатомия-килл-гейт → (1) Rust core + parity-тесты (cargo) → (2) shadow-diff в CI → (3) A/B ×2 → (4) TASK-148 promotion flow. INJECTS-ONLY, 0 sandbox boots.
- **Kill-criteria (полные):** парити-промах > 0 на 20k тиках; A/B < 3%; JNI self-time модуля > 2% (§8 закон); задержка отправки апдейтов лодки (видимость) — регресс > тик.
