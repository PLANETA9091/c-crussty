- Источники: 20 zip-артефактов world3-bench (G24/A7/A8-кэш + 2 новых normtool-скачка

  run верифицирован GitHub API). Данные: lab/raw_polls.json, фит: lab/ramp_fit.json,
  скрипты: scripts/w3_ramp_extract.py + w3_ramp_fit.py.
- Модель (по ТЗ): poll[i] = plateau·(1−exp(−i/τ)) + шум, i = 0-based индекс C55-валидных
  поллов; grid τ 0.15..30 × LSQ-plateau. Контроль: nonparam-plateau = median(last-2 поллов);
  контроль-2: 3-параметрический floor-вариант (plateau−A·e^{−i/τ}) — НЕ идентифицируем на 5
  точках (τ улетает в grid-edge 30, plateau 6-11 TPS, экстраполяция расходится) ⇒ free-3p
  фит для normtool недопустим, только last-k или fixed-shape.

## Числа-модель
- **τ̂ = 0.69 полла** (IQR 0.68–0.79, range 0.49–1.03) ⇒ плато достигается к поллу 2-3
  (1−e^{−2/0.69}=0.94): CLAIM-форма «ramp 2-4 полла → плато» подтверждена.
- **Bias median-vs-plateau: медиана −12.53пп, mean −11.49пп** (2p-фит); nonparam-контроль
  −13.73пп (mean −13.35пп ± 4.25пп по 16 чистым 5-полльным ранам). **17/18 ранов ≤ −2пп**
  (знаковый тест p≈2⁻¹⁷) → систематика, не шум.
- Естественный эксперимент 36369278270 (11 поллов): явное плато 2.6×6 → C55-медиана 10 поллов
  −0.24пп vs −12.5пп типовых 5-полльных ⇒ bias ∝ 1/n, ramp реален и стабилен всё окно.
- Дифференциал: σ(bias) ≈ 4.25пп по ранам — ramp вносит ~±4пп разброса в парные norm-дельты
  (тот же seed-42 фиксчер, корреляция серий — независимость ограничена).
