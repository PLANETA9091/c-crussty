## 3. Гипотеза H-W7a/b: t_stab линейно/лог от секунд? (задача 3, закон 14a)

- **H-W7a линейно** t_stab = a·T: склоны по ячейкам 450s→~0.89-1.0 · 600/640→~0.67-0.83 ·
  600/960→~0.42 · 900→~0.33 — разброс ×2.7, монотонно ВНИЗ с длиной окна → предсказание
  t_stab(900) ≈ 2×t_stab(450) провалено (наблюдение 0.75×) → **REFUTED**.
- **H-W7b лог** t_stab = a·ln T: a = 62-78 (r640-семья) vs 39 (r960) — не константа → **REFUTED**.
- Выживающая модель: **t_stab window-НЕзависим ≈ const ∈ [250,500]s** (налив 150k-сцены/
  heap один раз — A4-инвариант (b) young-декелерация 122→45.5 ms/s-soak, Full GC константен).
  Ценз: 150/300s окна = правый хвост (t_stab > окна, ≤ полл-серию не видим).
- Вердикт-класс: **REFUTED_CENS** с потолком ~500s; число-вердикт = склон-разброс ×2.7 (лин)
  / 62-78-vs-39 (лог).
