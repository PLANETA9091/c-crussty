2. АРХИТЕКТУРА: Native Chunk Factory
----------------------------------------------------------------
Чанк = чистая функция f(seed, datapack, версия, x, z) -> NBT чанка.
Реализуем f целиком в Rust, Java получает готовые байты.

Ступени доставки (каждая отгружается и измеряется отдельно):
  A) offline region writer: бинарник пишет .mca напрямую, без сервера
  B) виртуальный регион-файл: хук на путь "чанка нет на диске -> генерировать"
     (точку найти в Moonrise chunk IO), вместо Java-генерации возвращаем NBT
     из Rust, один JNI-вызов на чанк, сервер читает как загруженный FULL-чанк
  C) стадийные мосты (noise+surface+carve -> секции), промежуточные замеры

Ключевые идеи по ускорению:
  K1  Компилятор worldgen-графа (датапак -> IR -> оптимизированный план)
  K2  Точная интервальная отсечка по границам density-узлов
  K3  Дедупликация между чанками (карверы, 2D-поля, аквиферы, сканы структур)
  K4  Секционно-разреженная модель, свет только в активных секциях
  K5  Порт features/структур по тирам с откатом в Java
  K6  Дисциплина бит-в-бит, эталон = настоящая JVM
