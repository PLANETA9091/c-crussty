## 2. THREE measured design fixes during bring-up (each archived in RAW)

1. **Exact-bits key never hits** (pilot_exactbits_key/): ground items apply
   friction ×0.98/tick forever — the AABB rebuilds with new double bits every
   tick → hit-rate ≈ 0 → armed arm SLOWER than dormant (B 3.29 vs A 2.19
   CPU-s). Fix: quantize the key to INTEGER CELL BOUNDS (the negative outcome
   is cell-set-determined; sub-cell drift is invisible to it, bit-exact).
2. **Single-entry cache thrashed by tag alternation**: each entity runs TWO
   scans per baseTick (WATER then LAVA) — one slot per entity alternates and
   never hits (measured hit_rate 2.0% before the fix). Fix: per-entity slot
   array (≤4 tags, TagKey-identity indexed).
3. **Summon harness determinism**: `forceload add` takes BLOCK coordinates —
   chunk-looking args marked ONE chunk; spawn chunks are not auto-kept-loaded
   in this Purpur build; entities spawned into transiently-loaded chunks were
   saved to disk on unload and vanished from `@e` (summoned=0 measurable
   load). Fix: block-coord forceload (`-576 -368 -528 -320` = 9 chunks) +
   accumulated-log summon delta counting.

## 3. ENGINE CRITICAL FIX (CRUSSTY repo — the session's biggest catch)

`runtime/src/lib.rs` class_file_load_hook passed `name.as_ptr()` of a Rust
`String` (NOT NUL-terminated) to the C-ABI plugin hook; every consumer's
C-string scan ran past the end into unrelated heap bytes → **hook-name
matching was heap-layout-dependent**: PerlinNoise matched (its name String
happens to sit next to a NUL), `net/minecraft/world/entity/Entity` silently
missed — whole-body patches became no-ops with `retransform rc=0` and no
"hook serve" line. Every class hook in the project was
nondeterministically disabled. Fixed by passing a NUL-terminated CString
copy (infallible for class names); deployed as libcrussty_runtime.so
(backup: libcrussty_runtime.so.bak_prefix_nul). Post-fix chain: pristine
sighting 205458 B → hook serve 204078 B → armed rc=0 → self-test passed.
Evidence: grep "[crussty-trace] 'net/minecraft/world/entity/Entity'" (1
dispatch at load, ZERO at retransform pre-fix) + CRUSSTY_TRACE_HOOKS runs
(RAW: jfrproof_*, /tmp/trace_boot*.log).
