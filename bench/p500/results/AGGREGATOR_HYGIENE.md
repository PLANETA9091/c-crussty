## 2. Changes made (aggregate_p500.py only)

1. **Explicit duplicate-variant policy** — `dedupe()` replaced by `collapse()`:
   * primary row = min-median, ties keep the earliest file row (bit-exact v2
     semantics — no previously reported median can change);
   * every additional repeat is RETAINED and reported as `<method>#variantK`
     (K = 2, 3, … in (median, row-index) order) in the per-group tables and a new
     report section "Duplicate collapse (variant policy)" with greppable
     `DUP-VARIANT g<gid> <class> <method>#variantK med=… kept-primary=…` lines;
   * variants never form pairs (they are repeat measurements of the same kernel);
   * report header now exposes `raw RESULT rows: 185, collapsed variant rows: 56`
     next to the unchanged `kernels measured: 129`.
2. **Unpaired-kernel policy** — every unpaired kernel gets a stable sorted
   machine-greppable line `UNPAIRED g<gid> <class> <method> kind=<kind> reason="…"`
   (report + `AGGREGATOR-WARN` on stderr). New `--strict` flag exits 2 when any
   unpaired kernel exists (CI-friendly); default stays warn-only (exit 0).
3. **Multi-pair warnings** — now structured, sorted, machine-greppable:
   `MULTI-PAIR g<gid> <class> type=many-to-one old=<m> alts=<n> <alt1>,<alt2>,…`
   (ambiguous-tie form: `type=ambiguous alt=<m> stem-suffix=<n> candidates=…`).
   Emitted to the report and mirrored to stderr as `AGGREGATOR-WARN …`.
4. **`--check` mode** — re-derives the entire collapse/pairing from the raw TSV and
   diffs it against a checked-in expected-summary file
   (`bench/p500/results/p500_expected_summary.tsv`, generated by `--write-expected`).
   No timestamps; line kinds COUNTS / KERNEL / VARIANT / PAIR / UNPAIRED / MULTI /
   NOTE (the 70 SINK parity rows in the raw TSV are captured as NOTE lines).
   Exit 0 = match, 1 = drift (prints `−` expected-only / `+` derived-only lines),
   2 = expected file missing.

Self-test extended 34 → 51 assertions (duplicate fixtures, tie-break fixture,
greppable MULTI format, strict exit codes, expected-summary round trip + drift).
