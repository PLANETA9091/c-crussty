   measured window runs the lever" → в измеряемом окне (топап-скан/drain) callbacks живы.

   item age 6000t ⇒ ~17.7 items/tick turnover); путь тика = region workers → removal
   потенциально off-main.
4. 527-368: topupCtr* = plain long; bump() += delta из @EventHandler; resync на main:
   topupCtr* = aliveItems — не-атомарный RMW vs bump = data race по JMM.

  0.1% коллизий ≈ 48 единиц ≈ 2.5% дефицита 1.9k — не сцена-фатально, но счётчик = ground

  deficit-всплеск до TOPUP_PER_TICK_MAX=100/тик до ресинка.
