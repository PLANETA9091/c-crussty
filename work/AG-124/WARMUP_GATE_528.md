## 1. Алгебра bias
Окно W = τ_w (warmup) + τ_s (стационар), ρ = τ_w/W. Замедление тика в warmup r = m_w/m_s > 1.

    TPS_report / TPS_true = 1 / (1 + ρ·(r−1))

Якорь СИСТЕМАТИЧЕСКИ ЗАНИЖАЕТ stationary-TPS (никогда не завышает).

### Верхняя граница r из CPU-композиции (AG-88)
Warmup- overhead = C2-JIT 20% + GC 3.3% = 23.3% ALL. При полной TPS-чувствительности:
    r ≤ 1/(1−0.233) = 1.30 (CPU-bound верх; реал ниже: AG-72 «не cpu-bound» 37-58%,
мега-тик = barrier-wait one-off). Рабочий коридор r = 1.1–1.3.

### Оценка ρ
spark w1 = 430 тиков @ 7.16 tps ≈ 60s. C2-JIT 20% ALL усреднён по ПОЛНОЙ 600s-ноге
→ компиляция тянется минуты: τ_w ∈ [60, 300]s 600s-ноги → ρ ∈ [0.10, 0.50].
